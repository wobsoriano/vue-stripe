## Nuxt module

Vue Stripe ships an optional Nuxt module. It auto-imports every component and
composable, and gives you a lazily constructed Stripe Node client on the
server.

The module requires Nuxt 4 or later.

### Installation

```bash
npm install vue-stripe @stripe/stripe-js
```

Add the module to your config:

```ts
export default defineNuxtConfig({
  modules: ['vue-stripe/nuxt'],
})
```

If you want the server half, install the Stripe Node SDK too. It is an optional
peer dependency, so client-only projects never download it.

```bash
npm install stripe
```

### Configuration

Set your keys through the `stripe` config key or through environment variables.
Prefer environment variables in production.

```ts
export default defineNuxtConfig({
  modules: ['vue-stripe/nuxt'],
  stripe: {
    publishableKey: 'pk_test_xxx',
    secretKey: 'sk_test_xxx',
  },
})
```

```bash
NUXT_PUBLIC_STRIPE_PUBLISHABLE_KEY=pk_live_xxx
NUXT_STRIPE_SECRET_KEY=sk_live_xxx
```

The publishable key lands on `runtimeConfig.public.stripe`. The secret key stays
on the private branch and is never sent to the browser.

#### Options

| Option | Type | Default | Description |
| --- | --- | --- | --- |
| `publishableKey` | `string` | `''` | Publishable key, exposed to the client |
| `secretKey` | `string` | `''` | Secret key, server only |
| `apiVersion` | `string` | `''` | Stripe API version for the server client |
| `server.enabled` | `boolean` | `true` | Register `useServerStripe` |
| `server.options` | `object` | `{}` | Extra options passed to the Stripe Node client |
| `components` | `boolean \| { prefix }` | `true` | Component auto-registration |
| `composables` | `boolean` | `true` | Composable auto-imports |

### Loading Stripe.js

The module does not load Stripe.js for you. You pass a Stripe instance to the
components, exactly as you would without Nuxt and exactly as
`@stripe/react-stripe-js` works. The module's job is to auto-import the
components and composables, and to give you the publishable key through
runtime config.

```vue
<script setup>
import { loadStripe } from '@stripe/stripe-js'

const config = useRuntimeConfig()
const stripe = await loadStripe(config.public.stripe.publishableKey)

const options = {
  mode: 'payment',
  amount: 1099,
  currency: 'usd',
}
</script>

<template>
  <Elements :stripe="stripe" :options="options">
    <PaymentElement />
  </Elements>
</template>
```

`loadStripe` is the only thing you import. `Elements`, `PaymentElement`, and
`useRuntimeConfig` are all auto-imported.

The `stripe` prop accepts a `Stripe` instance, a promise resolving to one, or
`null`. Passing `null` during server rendering is supported, so a ref based
approach works if you prefer to load after mount.

### Using Stripe on the server

`useServerStripe(event)` is auto-imported inside `server/`. It builds the client
on first use and caches it for the lifetime of the process.

```ts
export default defineEventHandler(async (event) => {
  const stripe = await useServerStripe(event)

  const intent = await stripe.paymentIntents.create({
    amount: 1099,
    currency: 'usd',
    automatic_payment_methods: { enabled: true },
  })

  return { clientSecret: intent.client_secret }
})
```

### Component names

Root components keep their own names. Checkout components take a `Checkout`
prefix, because several names exist in both entry points and
`ShippingAddressElement` behaves differently in each.

| Import path | Registered as |
| --- | --- |
| `vue-stripe` | `<Elements>`, `<PaymentElement>`, `<AddressElement>`, `<TermsElement>`, and every other root export under its own name |
| `vue-stripe/checkout` | `<CheckoutElementsProvider>`, `<CheckoutFormProvider>`, `<CheckoutForm>`, `<CheckoutPaymentElement>`, `<CheckoutExpressCheckoutElement>`, `<CheckoutTaxIdElement>`, `<CheckoutCurrencySelectorElement>`, `<CheckoutContactDetailsElement>`, `<CheckoutTermsElement>`, `<CheckoutBillingAddressElement>`, `<CheckoutShippingAddressElement>` |

Add a global prefix if you want everything namespaced:

```ts
export default defineNuxtConfig({
  modules: ['vue-stripe/nuxt'],
  stripe: {
    components: { prefix: 'Stripe' },
  },
})
```

That gives you `<StripePaymentElement>` and `<StripeCheckoutPaymentElement>`.

Set `components: false` to turn registration off and import explicitly instead.

### Auto-imported composables

`useStripe`, `useElements`, `useCheckout`, `useCheckoutElements`, and
`useCheckoutForm`. Set `composables: false` to disable.
